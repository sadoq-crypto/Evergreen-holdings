# Evergreen Holdings Static Website

This folder is a complete static mockup with no React, Node.js, database, or build step.

## Preview locally

Open `index.html` directly in a browser.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload everything inside this folder, keeping the `assets` directory intact.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The contact form is visual only. Connect it to a form service or backend before using it for real enquiries.
